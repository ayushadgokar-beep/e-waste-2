How to read the results

BFS minimizes edge count in an unweighted graph. DFS does not promise a shortest path. Greedy Best-First follows the heuristic and may miss a lower-cost path. A* uses f(n) = g(n) + h(n); here h(n) = 0, so it behaves like uniform-cost search.

One small simulated graph is not enough to conclude that an algorithm is generally superior. BFS minimizes edge count only when edges are treated as unweighted; A* minimizes cost when its heuristic is admissible and consistent. Greedy Best-First and DFS do not generally guarantee a minimum-cost route.

PROJECT GUIDE

About EcoCycle AI

A beginner-friendly AI practical project for responsible e-waste decisions.

Purpose

EcoCycle AI combines a small Flask application, local JSON storage, and transparent examples of classic AI algorithms. It helps students explore possible device pathways and algorithm behavior through a simulated collection network.

No real collection companies, GPS, live travel distances, or processing services are connected.

Technology

PythonFlaskJSON filesVanilla JavaScriptpytest

Practical mapping

  1. State-space search BFS through processing states
  2. BFS and DFS Sample collection graph traversal
  3. Greedy and A* Heuristic-based route search
  4. Min-Conflicts Resource allocation CSP
  5. Propositional logic Rule facts and conclusions
  6. Unification Terms, substitutions, occurs check
  7. Reflex agent Current observation only
  8. Model-based agent Processing history affects action
  9. Minimax Small adversarial choice tree
  10. Alpha-Beta Pruned search of same game tree

See docs/ for architecture, mapping, and viva questions.
